# 🚀 Jeremy Felix - Portfolio Website

Website portfolio pribadi yang dibuat untuk keperluan enrichment magang, semester 5 Software Engineering.

## 🌐 Live Preview

Buka file `index.html` di browser untuk melihat hasilnya.

## ✨ Fitur

- **Dark Theme** - Desain modern dengan warna gelap
- **Responsive** - Tampil sempurna di desktop maupun mobile
- **Animasi Smooth** - Transisi dan hover effect yang halus
- **Sections:**
  - 🏠 Hero Section (dengan foto placeholder)
  - 💼 Services / What Can I Do
  - 📁 Portfolio Projects
  - 🛠️ Skills & Tech Stack
  - 👤 About Me
  - 📬 Contact Form
  - 🔝 Back to Top Button

## 🛠️ Teknologi

- **HTML5** - Struktur halaman
- **Tailwind CSS** (via CDN) - Styling & layout
- **Font Awesome** (via CDN) - Icons
- **Google Fonts** (Inter) - Typography
- **Vanilla JavaScript** - Interaktivitas

## 📸 Cara Menambahkan Foto

Ganti bagian placeholder foto di `index.html`:

```html
<!-- Temukan bagian ini dan ganti dengan tag img -->
<div class="w-64 h-72 ...">
  <!-- Ganti ini: -->
  <i class="fas fa-user ..."></i>
  <!-- Dengan ini: -->
  <img src="foto-kamu.jpg" alt="Jeremy Felix" class="w-full h-full object-cover" />
</div>
```

## 📂 Struktur Project

```
Portofolio/

├── README.md        # Dokumentasi
```
